AUTHENTICATION
--------------
All protected endpoints require:
  Header: Authorization: Bearer {access_token}
  Header: Accept: application/json
  Header: X-App-Version: 2.0.0
  Header: X-Platform: ios|android|web

Tokens expire in 24 hours. Use /auth/refresh to renew.
Refresh tokens expire in 30 days.

SECTION 1: AUTHENTICATION
================================================================

POST /auth/otp/send
  Send an OTP code to an email address or phone number.
  Body: {
    "identifier": "string (email or phone)",
    "type":       "email|phone",
    "purpose":    "registration|password_reset|login_2fa|email_change|phone_change"
  }
  Returns 200: {
    "message":      "Code sent successfully",
    "expires_in":   600,
    "resend_after": 58
  }
  Returns 422: { "message": "Already sent. Please wait 58 seconds before resending." }
  Returns 429: { "message": "Too many attempts. Please try again later." }

POST /auth/otp/verify
  Verify an OTP code. Returns a short-lived verification token.
  Body: {
    "identifier": "string (same as send)",
    "code":       "string (6 digits)",
    "purpose":    "registration|password_reset|..."
  }
  Returns 200: {
    "verified":           true,
    "verification_token": "string (use in /auth/register or /auth/password/reset)"
  }
  Returns 422: { "message": "Invalid code", "attempts_remaining": 4 }
  Returns 429: { "message": "Too many failed attempts. Request a new code." }

POST /auth/register
  Register a new user account (requires pre-verified OTP).
  Body: {
    "first_name":            "string",
    "last_name":             "string (optional)",
    "username":              "string (3-30 chars, alphanumeric + underscores + periods)",
    "password":              "string (min 8 chars)",
    "password_confirmation": "string",
    "birthday":              "YYYY-MM-DD",
    "email":                 "string (if registered by email)",
    "phone":                 "string (if registered by phone)",
    "verification_token":    "string (from /auth/otp/verify)",
    "device_id":             "string",
    "device_name":           "string",
    "platform":              "ios|android|web"
  }
  Returns 201: {
    "access_token":  "string",
    "refresh_token": "string",
    "expires_in":    86400,
    "user": { UserResource }
  }
  Returns 422: { "message": "Validation error", "errors": {...} }
  Returns 409: { "message": "Username already taken" }

POST /auth/login
  Login with email/username and password.
  Body: {
    "email":       "string (email or username)",
    "password":    "string",
    "device_id":   "string",
    "device_name": "string",
    "platform":    "ios|android|web"
  }
  Returns 200: { "access_token", "refresh_token", "expires_in", "user" }
  Returns 401: { "message": "Invalid credentials" }
  Returns 423: { "message": "Account suspended", "suspension_ends_at": "...", "reason": "..." }
  Returns 403: { "message": "Account banned", "reason": "..." }

POST /auth/refresh
  Refresh an expired access token.
  Body: { "refresh_token": "string" }
  Returns 200: { "access_token", "refresh_token", "expires_in" }
  Returns 401: { "message": "Refresh token expired. Please log in again." }

POST /auth/logout
  Revoke current session token. [AUTH REQUIRED]
  Returns 200: { "message": "Logged out successfully" }

POST /auth/logout-all
  Revoke all user sessions. [AUTH REQUIRED]
  Returns 200: { "message": "All sessions revoked" }

POST /auth/password/forgot
  Send OTP for password reset (replaces email-link method).
  Body: {
    "identifier": "string (email or phone)",
    "type":       "email|phone"
  }
  Returns 200: { "message": "Reset code sent", "expires_in": 600 }

POST /auth/password/reset
  Reset password using verified OTP token.
  Body: {
    "verification_token":    "string (from /auth/otp/verify with purpose=password_reset)",
    "password":              "string (min 8 chars)",
    "password_confirmation": "string"
  }
  Returns 200: { "message": "Password updated successfully" }
  Returns 422: { "message": "Invalid or expired reset token" }

================================================================
ERROR RESPONSE FORMAT
================================================================

All errors return:
{
  "message": "Human readable error message",
  "errors":  { "field": ["validation error"] },  // Only on 422
  "code":    "ERROR_CODE_STRING"                  // Machine-readable
}

HTTP Status Codes:
  200 - OK
  201 - Created
  204 - No Content
  400 - Bad Request
  401 - Unauthorized (not authenticated)
  403 - Forbidden (authenticated but not authorized)
  404 - Not Found
  409 - Conflict
  422 - Unprocessable Entity (validation error)
  423 - Locked (account suspended/banned)
  429 - Too Many Requests (rate limited)
  500 - Internal Server Error
  503 - Service Unavailable (maintenance mode)


================================================================
RATE LIMITING
================================================================

Default limits (per IP per minute):
  Public endpoints:    60 requests/min
  Auth endpoints:      10 requests/min
  Authenticated:       120 requests/min
  Admin endpoints:     300 requests/min
  Media upload:        20 requests/min

Headers returned:
  X-RateLimit-Limit:     int
  X-RateLimit-Remaining: int
  X-RateLimit-Reset:     unix timestamp
