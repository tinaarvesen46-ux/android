This document lists every third-party service VibeChat integrates with,
where to obtain credentials, and how to plug them into the Flutter app

Configuration file references:

  Laravel .env   → Backend-Setup-Guide.txt (STEP 2)


================================================================
1. GOOGLE SIGN-IN
================================================================

Service: Google Identity Services / OAuth 2.0
Used for: Social login (Android + iOS + Web)

STEP 1 — Create Firebase / Google Cloud project:
  https://console.firebase.google.com/
  → Add project → name it "VibeChat"
  → (Or use existing GCP project at https://console.cloud.google.com/)

STEP 2 — Add Android app to Firebase:
  Package name: com.darvin.vibechat
  SHA-1 (debug):
    keytool -list -v -keystore ~/.android/debug.keystore \
            -alias androiddebugkey -storepass android -keypass android
  SHA-1 (release):
    keytool -list -v -keystore YOUR_KEYSTORE.jks -alias YOUR_ALIAS
  Download → google-services.json → place in android/app/

STEP 3 — Add iOS app to Firebase:
  Bundle ID: com.darvin.vibechat
  Download → GoogleService-Info.plist → place in ios/Runner/

STEP 4 — Enable Google Sign-In:
  Firebase Console → Authentication → Sign-in method → Google → Enable

STEP 5 — Get Web Client ID:
  Google Cloud Console → APIs & Services → Credentials
  → The "Web client (auto created by Google Service)" entry
  → Copy the Client ID (ends in .apps.googleusercontent.com)
  → Paste into lib/config/oauth_config.dart → googleWebClientId

STEP 6 — Flutter pubspec.yaml additions needed:
  google_sign_in: ^6.2.1
  firebase_core: ^3.6.0
  firebase_auth: ^5.3.1      # (optional — if using Firebase Auth)

STEP 7 — android/app/build.gradle.kts:
  Add at top: id("com.google.gms.google-services")
  android/build.gradle.kts dependencies:
    classpath("com.google.gms:google-services:4.4.2")

STEP 8 — Backend verification:
  POST /api/v1/auth/google
  Body: { "id_token": "<google id_token>" }
  Laravel: use google-auth-library or firebase-php to verify token

2. APPLE SIGN-IN
================================================================

Service: Sign In with Apple
Used for: Social login (required on iOS if any 3rd-party login is offered)

STEP 1 — Apple Developer Account:
  https://developer.apple.com/ — requires paid membership ($99/yr)

STEP 2 — Enable capability on App ID:
  Certificates, IDs & Profiles → Identifiers
  → com.darvin.vibechat → Edit → Sign In with Apple → Enabled

STEP 3 — Create Service ID (for Android/Web):
  Identifiers → (+) → Services IDs
  Identifier: com.darvin.vibechat.siwa
  Description: VibeChat Sign In with Apple
  Enable Sign In with Apple → Configure:
    Primary App ID: com.darvin.vibechat
    Domains: vibechat.app
    Return URLs: https://vibechat.app/auth/apple/callback

STEP 4 — Create Key:
  Keys → (+) → Enable Sign In with Apple → Configure → Select App ID
  Download .p8 file → store SECURELY (cannot re-download)
  Note the Key ID shown after creation

STEP 5 — Update lib/config/oauth_config.dart:
  appleTeamId     = 10-char ID shown top-right in Apple Developer portal
  appleKeyId      = Key ID from step 4
  appleServiceId  = com.darvin.vibechat.siwa
  appleRedirectUri= https://vibechat.app/auth/apple/callback

STEP 6 — Xcode (iOS):
  Signing & Capabilities → (+) Capability → Sign In with Apple
  (This adds the entitlement automatically)

STEP 7 — Flutter pubspec.yaml addition:
  sign_in_with_apple: ^6.1.4

STEP 8 — ios/Runner/Info.plist:
  (No additional key required — entitlement handles it)

STEP 9 — Backend verification:
  POST /api/v1/auth/apple
  Body: { "code": "<auth_code>", "id_token": "<apple id_token>" }
  Laravel: use patrickbussmann/oauth2-apple or parse JWT manually

  .env additions:
    APPLE_TEAM_ID=YOUR_TEAM_ID
    APPLE_KEY_ID=YOUR_KEY_ID
    APPLE_SERVICE_ID=com.darvin.vibechat.siwa
    APPLE_PRIVATE_KEY_PATH=/path/to/AuthKey_XXXXXXXX.p8

3. SMTP / EMAIL SERVICE
================================================================

See lib/config/smtp_config.dart for full documentation.

Recommended: Mailgun
  https://www.mailgun.com/
  Free tier: 100 emails/day (sufficient for development)

  Laravel .env (Mailgun):
    MAIL_MAILER=mailgun
    MAILGUN_DOMAIN=vibechat.app
    MAILGUN_SECRET=key-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    MAIL_FROM_ADDRESS=noreply@vibechat.app
    MAIL_FROM_NAME=VibeChat

  Verify domain by adding DNS records:
    TXT: "v=mailgun.org" (SPF)
    TXT: (DKIM key from Mailgun dashboard)
    CNAME: email.vibechat.app → mailgun.org

Alternative: SendGrid
  https://sendgrid.com/
  Laravel .env:
    MAIL_MAILER=smtp
    MAIL_HOST=smtp.sendgrid.net
    MAIL_PORT=587
    MAIL_USERNAME=apikey
    MAIL_PASSWORD=SG.xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    MAIL_ENCRYPTION=tls

5. PUSH NOTIFICATIONS (FCM / APNs)
================================================================

Service: Firebase Cloud Messaging (Android + iOS + Web)

STEP 1 — Firebase project (same as Google Sign-In step 1)

STEP 2 — FCM Server Key:
  Firebase Console → Project Settings → Cloud Messaging
  → Server key (legacy) OR create a new Service Account key (V1)

STEP 3 — iOS APNs configuration:
  Firebase Console → Project Settings → Cloud Messaging → iOS app
  → Upload APNs Auth Key (.p8):
    Apple Developer → Keys → Create Key → Apple Push Notifications service
    Download .p8 → Upload to Firebase

STEP 4 — Flutter packages:
  firebase_messaging: ^15.1.0
  flutter_local_notifications: ^17.2.0

STEP 5 — iOS Info.plist additions:
  <key>FirebaseAppDelegateProxyEnabled</key>
  <false/>

STEP 6 — Android AndroidManifest.xml (inside <application>):
  <service android:name="com.google.firebase.messaging.FirebaseMessagingService"
           android:exported="false">
    <intent-filter>
      <action android:name="com.google.firebase.MESSAGING_EVENT"/>
    </intent-filter>
  </service>

STEP 7 — Laravel backend:
  composer require laravel-notification-channels/fcm
  .env:
    FCM_SERVER_KEY=AAAAxxxxxxxx...  (legacy) OR use Service Account JSON

6. STRIPE (SUBSCRIPTIONS / PAYMENTS)
================================================================

Service: Stripe
Used for: VibeChat+ subscription payments (web/Android)
Note: iOS subscriptions must go through Apple IAP (see section 7)

STEP 1 — Create Stripe account: https://stripe.com/

STEP 2 — Get API keys:
  Dashboard → Developers → API keys
    Publishable key: pk_live_xxxxxxxxxxxxxxxxxxxxxxxx
    Secret key: sk_live_xxxxxxxxxxxxxxxxxxxxxxxx (NEVER put in Flutter code)

STEP 3 — Create Products:
  Dashboard → Products → Add Product
  Create 4 subscription plans matching your subscription_plans table

STEP 4 — Laravel .env:
  STRIPE_KEY=pk_live_xxxxxxxx
  STRIPE_SECRET=sk_live_xxxxxxxx
  STRIPE_WEBHOOK_SECRET=whsec_xxxxxxxx

STEP 5 — Flutter pubspec.yaml:
  flutter_stripe: ^11.1.0   # For Stripe Payment Sheet (Android/Web)

STEP 6 — AndroidManifest.xml (required by flutter_stripe):
  <activity android:name="com.stripe.android.paymentsheet.PaymentSheetActivity"
            android:exported="false"/>

7. APPLE IN-APP PURCHASES (iOS SUBSCRIPTIONS)
================================================================

Service: Apple StoreKit
Used for: VibeChat+ subscriptions on iOS (App Store mandates this)

STEP 1 — App Store Connect: https://appstoreconnect.apple.com/
  → Your App → Subscriptions → (+) Create Subscription Group
  Name: VibeChat Plus

STEP 2 — Create subscription products:
  com.darvin.vibechat.plus.monthly   — $4.99/month
  com.darvin.vibechat.plus.yearly    — $39.99/year
  com.darvin.vibechat.pro.monthly    — $9.99/month
  com.darvin.vibechat.pro.yearly     — $79.99/year

STEP 3 — Flutter pubspec.yaml:
  in_app_purchase: ^3.2.0

STEP 4 — Backend receipt verification:
  POST /api/v1/subscriptions/verify-iap
  Body: { "receipt": "<apple receipt data>", "platform": "ios" }
  Laravel: Apple's server-side receipt validation endpoint

8. GOOGLE PLAY BILLING (ANDROID SUBSCRIPTIONS)
================================================================

Service: Google Play Billing
Used for: VibeChat+ subscriptions on Android

STEP 1 — Google Play Console: https://play.google.com/console/
  → Your App → Monetize → Subscriptions → Create subscription
  (Match the same product IDs as Apple)

STEP 2 — Flutter uses same in_app_purchase package (section 7)

STEP 3 — AndroidManifest.xml:
  <uses-permission android:name="com.android.vending.BILLING"/>

STEP 4 — Backend:
  POST /api/v1/subscriptions/verify-iap
  Body: { "receipt": "<purchase token>", "platform": "android" }
  Laravel: Use Google Play Developer API to verify purchase

9. AWS S3 (MEDIA STORAGE)
================================================================

Service: Amazon S3
Used for: Avatar uploads, story media, cover photos

STEP 1 — Create AWS account: https://aws.amazon.com/

STEP 2 — Create S3 bucket:
  Name: vibechat-media
  Region: us-east-1 (or closest to your users)
  Block all public access: OFF (files served via CloudFront)

STEP 3 — Create IAM user:
  IAM → Users → Add User → Programmatic access
  Attach policy: AmazonS3FullAccess (or scoped policy for bucket only)
  Download access key ID + secret access key

STEP 4 — CloudFront distribution (recommended):
  Origin: vibechat-media.s3.amazonaws.com
  CNAMEs: media.vibechat.app
  → All media served via media.vibechat.app instead of direct S3 URLs

STEP 5 — Laravel .env:
  AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
  AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
  AWS_DEFAULT_REGION=us-east-1
  AWS_BUCKET=vibechat-media
  AWS_URL=https://media.vibechat.app

10. PUSHER (REAL-TIME MESSAGING)
================================================================

Service: Pusher Channels
Used for: Real-time message delivery, typing indicators, online status

STEP 1 — Create account: https://pusher.com/
  → Create new Channels app
  → Name: VibeChat
  → Cluster: choose closest to your server (mt1=US East, eu=EU)

STEP 2 — Get credentials:
  App ID, Key, Secret, Cluster

STEP 3 — Laravel .env:
  BROADCAST_DRIVER=pusher
  PUSHER_APP_ID=xxxxxxx
  PUSHER_APP_KEY=xxxxxxxxxxxxxxxx
  PUSHER_APP_SECRET=xxxxxxxxxxxxxxxx
  PUSHER_APP_CLUSTER=mt1

STEP 4 — Flutter pubspec.yaml:
  pusher_channels_flutter: ^2.1.0

STEP 5 — Flutter usage:
  PusherChannelsFlutter pusher = PusherChannelsFlutter.getInstance();
  await pusher.init(apiKey: 'YOUR_APP_KEY', cluster: 'mt1');
  await pusher.connect();
  await pusher.subscribe(channelName: 'private-user.USER_ID', ...);

SUMMARY TABLE — ALL KEYS NEEDED FOR LAUNCH
================================================================

Service            | Where to get               | Where to put
─────────────────────────────────────────────────────────────────
Google Client ID   | GCP Console / Firebase      | oauth_config.dart
google-services.json| Firebase                  | android/app/
GoogleService-Info | Firebase                    | ios/Runner/
Apple Team ID      | developer.apple.com         | oauth_config.dart
Apple Key ID       | developer.apple.com → Keys  | oauth_config.dart
Apple .p8 file     | developer.apple.com → Keys  | Backend server only
Mailgun Secret     | mailgun.com                 | Laravel .env
Vonage/Twilio creds| vonage.com / twilio.com     | Laravel .env
FCM Server Key     | Firebase Console            | Laravel .env
APNs Auth Key      | developer.apple.com → Keys  | Firebase Console
Stripe Secret Key  | stripe.com                  | Laravel .env (only!)
Stripe Public Key  | stripe.com                  | Flutter (safe)
AWS Access Key     | AWS IAM Console             | Laravel .env (only!)
Pusher App Key     | pusher.com                  | Flutter + .env
Pusher Secret      | pusher.com                  | Laravel .env (only!)

SECURITY RULES:
  ✅ Safe in Flutter: Google client IDs, Stripe publishable key, Pusher app key
  ❌ NEVER in Flutter: Stripe secret, AWS secret, Apple .p8, Pusher secret,
                        any password or API secret
