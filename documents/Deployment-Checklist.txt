================================================================
EMERGENCY CONTACTS & RUNBOOK
================================================================

Maintenance mode:
  PUT /admin/settings
  Body: { "settings": { "maintenance_mode": "true" } }
  (Or set in system_settings table directly via SQL)

Emergency database backup:
  mysqldump -u root -p vibechat_production > emergency_backup.sql

Clear Laravel cache (if stale config):
  php artisan cache:clear
  php artisan config:clear
  php artisan route:clear

Restart queue workers:
  supervisorctl restart vibechat-worker:*

View recent errors:
  tail -f storage/logs/laravel.log
