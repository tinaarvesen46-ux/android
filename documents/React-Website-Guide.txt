OVERVIEW
--------
This guide covers building the VibeChat web portal using
React 18 + TypeScript + Tailwind CSS v3. This is a separate
project from the Flutter mobile app — it serves as the
web dashboard for users, creators, and staff.

Pages to build:
  - Landing Page (public)
  - Login / Register / Forgot Password (public)
  - User Dashboard (authenticated)
  - Creator Dashboard (creator accounts)
  - Support Dashboard (support staff)
  - Moderator Dashboard (moderator staff)
  - Admin Dashboard (administrators)

4.3 FORGOT PASSWORD PAGE (/forgot-password):

  Step 2 (/reset-password?token=...): Enter new password + confirm

SECTION 12: API CLIENT SETUP
================================================================

src/api/client.ts:
  import axios from 'axios';
  import { useAuthStore } from '../stores/authStore';

  const apiClient = axios.create({
    baseURL: import.meta.env.VITE_API_BASE_URL,
    headers: { 'Accept': 'application/json', 'X-Platform': 'web' }
  });

  // Attach token to every request
  apiClient.interceptors.request.use((config) => {
    const token = useAuthStore.getState().accessToken;
    if (token) config.headers.Authorization = `Bearer ${token}`;
    return config;
  });

  // Handle 401: attempt refresh, then logout
  apiClient.interceptors.response.use(
    (response) => response,
    async (error) => {
      if (error.response?.status === 401) {
        try {
          await useAuthStore.getState().refreshToken();
          return apiClient(error.config);
        } catch {
          useAuthStore.getState().logout();
          window.location.href = '/login';
        }
      }
      return Promise.reject(error);
    }
  );

  export default apiClient;
