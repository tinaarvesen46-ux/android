STEP 3: CREATE MIGRATIONS
================================================================

Create migration files in the order defined in Database-schema.txt.
Below is the pattern for the users migration:

php artisan make:migration create_users_table

# In the migration file:
Schema::create('users', function (Blueprint $table) {
    $table->id();
    $table->uuid('uuid')->unique()->default(DB::raw('(UUID())'));
    $table->string('username', 30)->unique();
    $table->string('email')->unique();
    $table->timestamp('email_verified_at')->nullable();
    $table->string('phone', 20)->nullable()->unique();
    $table->timestamp('phone_verified_at')->nullable();
    $table->string('password');
    $table->rememberToken();
    $table->enum('account_status', ['normal','verified','creator','suspended','banned','deleted'])->default('normal');
    $table->enum('staff_role', ['none','support','moderator','administrator'])->default('none');
    $table->enum('privacy_level', ['public','friends_only','private'])->default('public');
    $table->boolean('is_online')->default(false);
    $table->timestamp('last_seen_at')->nullable();
    $table->unsignedInteger('streak_days')->default(0);
    $table->date('streak_last_activity')->nullable();
    $table->boolean('two_factor_enabled')->default(false);
    $table->string('two_factor_secret')->nullable();
    $table->text('two_factor_recovery')->nullable();
    $table->unsignedTinyInteger('login_attempts')->default(0);
    $table->timestamp('locked_until')->nullable();
    $table->unsignedTinyInteger('warning_count')->default(0);
    $table->text('suspension_reason')->nullable();
    $table->timestamp('suspension_ends_at')->nullable();
    $table->timestamp('banned_at')->nullable();
    $table->text('ban_reason')->nullable();
    $table->softDeletes();
    $table->timestamps();
});

# Repeat for all 35 tables using the SQL schema as reference.
# Run all migrations:
php artisan migrate

STEP 11: GOOGLE & APPLE OAUTH BACKEND VERIFICATION
================================================================

Install verification libraries:
  composer require google/apiclient
  # OR simpler JWT verification:
  composer require firebase/php-jwt

For Google ID token verification (AuthController@google):

  use Google\Client as GoogleClient;

  public function google(Request $request) {
      $request->validate(['id_token' => 'required|string']);

      $client = new GoogleClient(['client_id' => config('services.google.client_id')]);
      $payload = $client->verifyIdToken($request->id_token);

      if (!$payload) {
          return response()->json(['message' => 'Invalid Google token'], 401);
      }

      $user = User::firstOrCreate(
          ['email' => $payload['email']],
          [
              'username'     => Str::slug($payload['name']) . '_' . Str::random(4),
              'display_name' => $payload['name'],
              'avatar_url'   => $payload['picture'] ?? null,
              'email_verified_at' => now(),
              'password'     => Hash::make(Str::random(32)),
          ]
      );

      $token = $user->createToken('google_login')->plainTextToken;
      return response()->json(['access_token' => $token, 'user' => $user]);
  }

config/services.php — add:
  'google' => [
      'client_id' => env('GOOGLE_CLIENT_ID'),
  ],

.env — add:
  GOOGLE_CLIENT_ID=YOUR_WEB_CLIENT_ID.apps.googleusercontent.com


For Apple Sign-In backend verification (AuthController@apple):

  # Install: composer require patrickbussmann/oauth2-apple
  # OR verify the JWT id_token manually using Apple's public keys:
  # https://appleid.apple.com/auth/keys

  public function apple(Request $request) {
      $request->validate([
          'code'     => 'required|string',
          'id_token' => 'required|string',
      ]);

      // Decode the JWT id_token (header.payload.signature)
      // Verify signature using Apple's public keys (fetched from /auth/keys)
      // Extract email and sub (Apple user ID) from payload

      $appleUserId = $decoded->sub;   // unique Apple user identifier
      $email       = $decoded->email ?? null;

      $user = User::firstOrCreate(
          ['apple_id' => $appleUserId],
          [
              'email'    => $email,
              'username' => 'apple_' . Str::random(8),
              'email_verified_at' => now(),
              'password' => Hash::make(Str::random(32)),
          ]
      );

      $token = $user->createToken('apple_login')->plainTextToken;
      return response()->json(['access_token' => $token, 'user' => $user]);
  }

.env — add:
  APPLE_TEAM_ID=YOUR_TEAM_ID
  APPLE_KEY_ID=YOUR_KEY_ID
  APPLE_SERVICE_ID=com.darvin.vibechat.siwa
  APPLE_PRIVATE_KEY_PATH=/secure/path/AuthKey_XXXXXXXX.p8

The Flutter EditUserScreen calls PUT /admin/users/{id} with:
  {
    "display_name":   "New Name",
    "username":       "new_username",
    "email":          "new@example.com",
    "phone":          "+1555000000",
    "bio":            "Updated bio",
    "location":       "New York, USA",
    "pronouns":       "they/them",
    "account_status": "verified",
    "staff_role":     "moderator",
    "privacy_level":  "public",
    "is_verified":    true,
    "password":       "newpassword123"   // only if changing password
  }

Admin\UserController@update implementation:

  public function update(Request $request, User $user) {
      $data = $request->validate([
          'display_name'   => 'sometimes|string|max:50',
          'username'       => 'sometimes|string|max:30|unique:users,username,' . $user->id,
          'email'          => 'sometimes|email|unique:users,email,' . $user->id,
          'phone'          => 'sometimes|nullable|string|max:20',
          'bio'            => 'sometimes|nullable|string|max:150',
          'location'       => 'sometimes|nullable|string|max:100',
          'pronouns'       => 'sometimes|nullable|string|max:30',
          'account_status' => 'sometimes|in:normal,verified,creator',
          'staff_role'     => 'sometimes|in:none,support,moderator,administrator',
          'privacy_level'  => 'sometimes|in:public,friends_only,private',
          'is_verified'    => 'sometimes|boolean',
          'password'       => 'sometimes|nullable|string|min:8',
      ]);

      if (isset($data['password'])) {
          $data['password'] = Hash::make($data['password']);
      }

      $user->update($data);

      // Log the admin action
      AdminAuditLog::create([
          'admin_id'    => auth()->id(),
          'action'      => 'user_edited',
          'target_type' => 'user',
          'target_id'   => $user->id,
          'details'     => json_encode(array_keys($data)),
      ]);

      return response()->json(['user' => $user->fresh()]);
  }

STEP 13: SMTP QUICK SETUP (MAILGUN)
================================================================

1. Sign up at mailgun.com (free: 100 emails/day)
2. Add domain: vibechat.app
3. Mailgun gives you DNS records — add them at your registrar:
   - TXT record for SPF
   - TXT record for DKIM
   - CNAME: email.vibechat.app → mailgun.org
4. Wait for domain verification (15 min to 24 hours)
5. Go to Domain Settings → SMTP credentials → Create credentials
6. Update .env:
   MAIL_MAILER=mailgun
   MAILGUN_DOMAIN=vibechat.app
   MAILGUN_SECRET=key-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   MAIL_FROM_ADDRESS=noreply@vibechat.app
   MAIL_FROM_NAME=VibeChat

7. Test in Laravel tinker:
   Mail::raw('Test email from VibeChat', function($m) {
       $m->to('yourtest@gmail.com')->subject('Test');
   });
