================================================================
INDEXING STRATEGY
================================================================

Primary indexes:
  - All tables have AUTO_INCREMENT BIGINT primary keys
  - UUIDs indexed for external API references
  - created_at indexed on high-volume tables

Composite indexes:
  - conversations: type + last_activity_at (feed queries)
  - messages: conversation_id + created_at (message pagination)
  - story_views: story_id + viewer_id (UNIQUE - prevent duplicates)
  - campaign_recipients: campaign_id + user_id (UNIQUE)
  - creator_analytics: user_id + date (UNIQUE - daily snapshots)

Foreign key cascade rules:
  - Child records CASCADE DELETE when parent user is deleted
  - Assignment/reviewer fields SET NULL on staff deletion
  - Email template deletion RESTRICTED if campaigns reference it

================================================================
SOFT DELETES
================================================================

Tables using soft deletes (deleted_at column):
  - users (deleted_at + banned_at)
  - messages (is_deleted + deleted_at + deleted_for)

All other tables use hard deletes with CASCADE rules.
Use Laravel's SoftDeletes trait on corresponding models.
